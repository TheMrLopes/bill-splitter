##  How to Run the Project
To run this project locally on your machine, follow these steps:

### 1. Prerequiriments
Python 3

Git


### 2. Clone the repository
```bash
git clone https://github.com/TheMrLopes/bill-splitter.git
````

### 3. Navigate to the project folder
```bash
cd ~/Bill Splitter
```

### 4. Run the script
```bash
python splitter.py
```
